## How `/loop` resumes work

1. Read this file.
2. Pick the highest-value unchecked item in **Open**.
3. Implement it.
4. Move the line to **Done** with a one-line summary of what landed.
5. If nothing remains in **Open**, stop the loop (omit `ScheduleWakeup`).

**Avoid** items that need:

- External wallet creds (Anchor devnet/mainnet deploy with a funded keypair).
- A live Seeker device for smoke testing.
- The user's keystore password.

For those, write the procedure into the relevant doc and check the doc item off
instead — the actual one-time human step stays in the doc.
